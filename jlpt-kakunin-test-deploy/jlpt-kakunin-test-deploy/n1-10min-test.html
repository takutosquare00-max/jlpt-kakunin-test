問題1 — 漢字の読み（3問）

＿＿の言葉の読み方として最もよいものを、1・2・3・4から一つ選んでください。

1彼の発言は極めて曖昧だった。
✅ 正解：1. あいまい — 「曖昧」=「あいまい」。vague / ambiguous。
2政府は新たな措置を講じた。
✅ 正解：3. そち — 「措置」=「そち」。措置を講じる = take measures。
3長年の懸案がようやく解決した。
✅ 正解：1. けんあん — 「懸案」=「けんあん」。pending issue / concern。
問題2 — 語彙（3問）
4あの政治家は国民の支持を（　）ために、さまざまな政策を打ち出した。
✅ 正解：3. 取り付ける — 「支持を取り付ける」は、交渉や働きかけによって相手の支持・同意を確保するという意味。「得る」も文法的には可能だが、「取り付ける」は能動的に相手から約束・合意を引き出すニュアンスがあり、「さまざまな政策を打ち出した」という戦略的な行動と最も合致する。N1では最も的確なコロケーションを選ぶ力が問われる。
5新しいプロジェクトが（　）に乗るまで時間がかかった。
✅ 正解：1. 軌道 — 「軌道に乗る」は「順調に進むようになる」という慣用表現。
6彼は何事も（　）こなす優秀な社員だ。
✅ 正解：2. そつなく — 「そつなくこなす」で「ミスなく手際よくやる」の慣用表現。1は「大雑把に」、3は「不器用に」、4は「いい加減に」の意味で、いずれも「優秀な社員」と矛盾する。
問題3 — 文法（5問）
7あの事件は社会に大きな衝撃を与えた（　）。
✅ 正解：3. に違いない — 「〜に違いない」で「きっと〜だ」という確信を表す。文脈から「衝撃を与えたに違いない」が最も自然。
8彼女の演技は観客を（　）やまない。
✅ 正解：2. 魅了して — 「〜てやまない」で「ずっと〜し続ける」の意味。「魅了してやまない」が慣用的。N1文法。
9彼が犯人だと言わん（　）の態度だった。
✅ 正解：1. ばかり — 「言わんばかりの」で「今にも言いそうな」の意味。N1文法。
10努力する（　）、結果はおのずとついてくるものだ。
✅ 正解：3. なり — 「〜するなり」で「〜さえすれば」の意味。ここでは努力さえすれば結果がついてくる。
11長年の研究の末、ついに新薬の開発に（　）。
✅ 正解：4. こぎつけた — 「〜にこぎつける」で「苦労して〜に到達する」の意味。N1語彙。
問題4 — 文の組み立て（2問）
12彼の ＿＿ ＿＿ ★ ＿＿ ものがある。
✅ 正解：4. まさに — 「彼の 芸術的な 才能には ★まさに 目を見張る ものがある。」語順：3→1→4→2（目を見張る = 驚嘆する）
13この問題は ＿＿ ＿＿ ★ ＿＿ ない。
✅ 正解：3. わけには — 「この問題は 放置して おく ★わけには いか ない。」語順：1→2→3→4（〜わけにはいかない = cannot / must not）
問題5 — 読解（5問）
言語の本質的機能は、単なる情報伝達にとどまらない。言語は思考の道具であり、世界を認識するための枠組みを提供する。サピア＝ウォーフの仮説によれば、使用する言語によって、人間の思考パターンや世界の捉え方が異なるとされる。この仮説には賛否両論あるが、少なくとも言語が認知に一定の影響を及ぼすという「弱い版」の仮説は、近年の研究によって支持されつつある。
14サピア＝ウォーフの仮説の「弱い版」とは何ですか。
✅ 正解：3 — 「言語が認知に一定の影響を及ぼす」が「弱い版」の内容。
